The proposed framework integrates a Multi-dimensional Lightweight Channel Attention (MLCA) mechanism into the C2PSA architecture to reinforce channel-spatial feature representation while maintaining limited computational overhead. Additionally, an information-preserving ADown module is introduced to minimize structural information loss during downsampling, and a high-resolution P2 detection layer is incorporated to optimize the utilization of shallow features for small-object detection. Furthermore, a Lightweight Dynamic Feature Aggregation Head (LDFH) is developed to adaptively model scale-aware, spatial-aware, and task-aware feature dependencies, thereby improving robustness across varying object distributions.
